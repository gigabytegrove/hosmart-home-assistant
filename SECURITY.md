# Security Policy

Please report suspected security vulnerabilities privately.

Do **not** open a public GitHub issue containing vulnerability details, credentials, tokens, private keys, authentication responses, or personal information.

Use GitHub private vulnerability reporting or a Security Advisory when available. If those options are unavailable, contact the maintainers privately through GitHub.

A useful security report should include:

- Affected integration version
- Description of the issue
- Potential impact
- Reproduction steps
- Sanitized supporting evidence

Please remove secrets and unrelated personal data before submitting logs, diagnostics, screenshots, or captures.
